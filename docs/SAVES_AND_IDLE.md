# 存档与离线生产

有限关卡、无限拓荒各有一个独立存档槽。保存包含道路、建筑、在建进度、岗位、原料与库存、运输队列和搬运工位置、教程、地图种子与探索范围、乡勇及当前战斗状态。切换模式会保存当前已开始的村庄，返回原模式可继续。选择「新局」会先确认，入村后才覆盖该模式旧档。

## 保存时机与状态

- 游戏中每三十秒自动保存；也可点击底栏「存档」或模式页「保存」。
- 切换模式、切到后台及正常退出时尝试保存。系统强制杀进程不保证执行退出回调，因此保留周期检查点。
- 原生引擎 File API 保存账号、项目隔离的本地副本，并保留上一次有效快照作为备份。
- 通过 Maker 官方 `clientCloud:Get/Set` 读取和写入当前 TapTap 账号云变量。只有成功回调后才显示「云端与本地已保存」。
- 加载时比较本地、备份与云端的保存时间及修订号。云端读取超时八秒后允许使用本地副本；延迟返回的读取不会覆盖正在玩的村庄。没有成功读过的云槽不自动覆盖，防止弱网时空白新局冲掉已有云档；重新进入该模式可重试云读取。
- Web 运行时的本地文件在刷新后可能丢失，因此浏览器端持久化依赖云端成功状态。原生手机本地副本独立保留。未承诺多人同时写入的服务器事务或防改时钟功能。

## 挂机规则

「挂机：开/关」位于模式页，随存档保存。离线期间不保持手机或服务器中的实时游戏进程；下次进入或从后台返回时，根据上次保存的时间补算生产，最多八小时，按一倍现实时间，不享受在线两倍速。

补算沿用同一套建造、岗位、原料、道路、资源储量及搬运逻辑，不直接凭空增加资源。分帧处理结算，期间阻止操作，完成后显示净资源变化并立即保存新的时间与结果，避免同一段时间被重复领取。超过八小时的部分不继续累积。

离线期间不消耗口粮、不进行饥饿伤害、不移动或结算敌人、不推进袭击倒计时，也不增加生存时长或守村分。已经开始的战斗保持原状态，回来后继续。主动暂停、已通关、已失败、未入村的存档不产生挂机收益。

## 验证范围

`tests/save_validate.lua` 覆盖序列化与真实引擎文件读写、在途运输引用重建、损坏主档回退、按模式隔离、云端回调及失败模拟、八小时上限、后台恢复与不重复领取。`tests/save_showcase.lua` 为恢复后离线结算界面的确定性截图夹具。真实 TapTap 账号的跨设备云存档最终以手机端成功回调和实机重进结果为准。
