# 开局引导与地图手势

进入新村庄后，里正谢伯以独立肖像和对话框讲解八个基础目标。点「明白，去做」会淡出对话框并留下任务入口；目标完成后，谢伯再次出现，说明结果并引导下一步。左上任务入口可重看当前对话，村务里可从第一步重读。任何一步都能点「跳过教程」进入自由经营；跳过与当前教程进度随村庄存档保存。

地图支持单指拖动、双指捏合缩放，缩放以两指中点下方的地块为锚点，范围为 0.55 到 1.8 倍。右上角小地图显示地形、道路、建筑和当前视角中心；点小地图可快速定位。打开右侧抽屉时小地图暂时收起，关闭抽屉后恢复。

里正肖像目前由游戏内的原创矢量绘制，后续可用 `assets/image/portrait-elder.png` 替换。其他手绘图集仍待导入。`tests/mentor_validate.lua` 和 `tests/map_touch_validate.lua` 用真实引擎检查引导、淡出、跳过、读档、手势锚点及小地图点按。
