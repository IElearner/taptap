# 像素测试版：独立验收执行表

范围：像素首测沿用现有 11 类建筑与既有经济闭环，不代表完整 27/32 建筑设计已经完成。旧 V12 和独立概念片的通过结论不复用。

角色方向是原创中国村民、大头短身、清楚外轮廓；不照搬其他游戏人物。基准世界视野 640×360，可拖移；原生标尺现采用 24–28 逻辑像素的角色身体、固定 40×48 动作格，常规建筑宽 144–192 像素（义仓 128）。工具举高不改变身体缩放。世界格 64×48，源图画布尺寸不等于人物高度；实际作业点必须与可见地基登记，不能直接把经济占格边界当作工具落点。
