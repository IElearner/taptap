# 山河里：经典经营战略界面改版

## 登录与进度

首屏是独立登录界面，而不是把所有设置堆到游戏地图上。
「TapTap 账号进入」验证引擎提供的 clientCloud.userId；没有平台身份时提示从 TapTap 打开，不伪造授权。
平台认证由 TapTap 宿主完成，游戏不收集密码。云端读取和保存仍以实际回调为准，不能把已识别账号等同于云同步成功。
「游客试玩」关闭云端通道，并以 guest_ 前缀单独保存本地进度，避免覆盖账号本地档。首次选择账号前不读写游戏存档。
登录选择在本次会话的模式切换中保留；重新启动游戏回到登录页。

## 交互

- 默认地图：资源栏、里正手札入口、归村与缩放、营造/村务/军务/系统四个入口。
- 同一时间只打开一个右侧抽屉，目录内容可以滚动。
- 营造：九种道路/建筑，显示成本；选中后自动收起目录进入放置，提供完成放置操作。
- 村务：八步教程、进度、继续或跳过教学。
- 军务：训练、防守、义仓修缮、无限模式拓荒和查看边疆。
- 系统：暂停/倍速、存档、离线生产开关、模式选择、带确认的新局。
- 点击建筑才显示详情与岗位，点击建筑屋顶也可选中。
- UI.Scale.DEFAULT 保持不变，文字设置最低可读字号，按钮设置最低 44 CSS 像素目标。

## 美术

Skin.lua 提供旧木纹、铜饰框、铆钉和按压反馈；WorldView 增加道路石块、草丛与分层树冠。
生成的原创美术沿用经典手绘等距经营 RTS 的细致材料质感，使用中国乡村主题，未使用原作素材。
Maker 的 generation=maker 设置已确认，两张素材均生成成功。完整来源记录见 art/redesign-generated.json。

**当前阻塞：** 图片 CDN tapcode-sce.spark.xd.com 在本次云环境内仍被代理拒绝，生成结果尚无法下载。
所需域名已写入环境设置草稿；用户发布设置后曾重试，当前实例仍返回 403，需等待网络规则实际可用后再重试原 URL。
未把未下载的美术描述为已部署，也未重复提交付费生成任务。

预留接入路径：
- assets/image/login-painting.png：1600×900 登录背景。
- assets/image/building-{kind}.png：从 1536×1536 九宫格图集检查后切出，每格 512×512。
- 图集预定顺序：store/house/farm；mill/kitchen/woodcutter；quarry/courier/barracks。
- **先查看真实图集**，核对顺序、透明背景和地面锚点，再裁切并调整 WorldView 的锚点；不能只按生成提示词认定正确。
- 通过 Maker generate_resource_meta 生成资源元数据后进行真实渲染验证。
- 图像尚未下载时保留原有矢量建筑回退；该回退不是手绘美术最终验收。

## 人物多样化

用户认可现有手绘风格，继续沿用；新增人物侧重年龄、性别、体态、服饰与职业差异。
四种搬运工身份：靛蓝壮年男性、赭黄成年女性、灰褐年长男性、青绿年轻成年女性；各有四朝向和对应负重版本。
新增职业素材规划：女性农夫、年长磨坊工、健壮伐木工、女性乡勇，各四朝向。
Characters.lua 按稳定的搬运工序号选择形象；负重只更换姿态，读档后不重新随机人物。
已竣工且有真实岗位的生产建筑显示工人；零岗位或施工阶段不凭空添加生产工人。
这属于表现层，不增加村民、不额外产出资源、不更改存档结构。
本轮真实引擎验证：tests/characters_validate.lua 的 18 项检查及原玩法 89 项检查通过，报告无 Lua/资源/引擎错误，静态检查零错误（仍有警告）。
