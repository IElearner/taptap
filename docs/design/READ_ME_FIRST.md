# 《山河里》设计资料导读

这是一套**玩法设计提案**，不是已实现功能清单，也不是测试版或上线结论。项目目标是借鉴《Knights and Merchants》（KaM）的劳力、生产与物流结构，做中国古村题材的即时聚落经营与战略游戏。配方、产率、周期、初始物资和战斗规则均需在 TapTap Maker / UrhoX Lua 原型中试玩校准。

## 先读哪些文件

- [首发经济与战略系统 GDD](CHINESE_VILLAGE_GDD.md)：玩法范围、32种建筑、岗位、蓝图建造、物流、军事、模式和教程。
- [32建筑空间与施工目录](BUILDING_CATALOG.md)：占格形状、入口、库存容量、运营最大在岗数、建造工作点和固定总劳动量。
- [建筑目录机器数据](building_catalog.json)：与经济 roster 同名同序的32种建筑空间规格。
- [机器可读经济数据](launch_economy.json)：建筑、配方、地块、资源、人口与标称经济参数。
- [经济数据校验器](validate_launch_economy.py)：只检查建筑名录、资源源汇结构和部分算术；不模拟实际生产、寻路、堵塞或游戏实现。
- [建筑目录校验器](validate_building_catalog.py)：只检查空间规格与经济建筑 roster 覆盖，不代表运行时放置测试。
- [KaM / Remake 机制研究](../research/KAM_REFERENCE_RESEARCH.md)：版本和数量口径、源码数据、网址、检索时间及访问限制。

## 首发设计范围

GDD 提案列出**32种可建建筑**。另有4类不计入建筑数量的地图地块：麦田、林地、矿区、渔场；道路和蓝图也不计建筑。农田保持简单，只覆盖麦田围栏、播种、三次劳作、成熟与休息。主要经营深度放在行业依赖、有限工人、物资分流、距离和道路运输，不叠加未经授权的儿童、疾病、天气或营养模拟。

工人是共享调度资源：同一普通村民可以按任务被派去搬运、修路或施工，不是固定的搬运工/建筑工职业；同一时间只能执行一个任务。专业生产岗位占用工时期间不能兼做其它任务，转岗后需要重新熟悉工作。食物链以“麦田→磨坊→饼坊→食堂用餐”为主；食堂是本作对 KaM `Inn` 餐饮服务角色的中文改名，不引入酒类生产或饮用需求。麸皮副产物还能进入“猪圈→屠宰→香肠/猪皮→食堂或制革”的支线。仓储、道路、搬运容量和生产排队决定链条能否顺畅运行。建筑运营最大在岗人数、四席食堂座位和施工工位彼此独立，空间提案见建筑目录。完整配方、目标产率与吞吐核算见 GDD 和 JSON；这些数字是可测的初始假设，不是平衡结论。

军事是首发设计范围的一部分：木、皮、铁、煤、金与马匹组成跨行业装备链，招募消耗金锭招募令、待命劳力和对应装备，军队需要口粮并参与有限关卡目标。建筑、兵种、装备、配方和有限/无限玩法详见 GDD。

## 验证种子与教学新档

JSON 中的 `validation_seed_buildings`、`validation_seed_stocks` 是为了静态检查配方可达性、启动互锁和口粮产能而设置的**验证种子档**。它预置多条工业链，不能当作教学新档或玩家首次开局。

GDD 中教学新档的设计目标是：16名成年村民、4间家院，以及村务堂、仓库、粮仓、农庄等基础设施；开档不赠送伐木场、锯木坊、石匠铺、磨坊、饼坊和食堂。建议教学新档库存：木料82、切石47、麦粒8、面饼96。伐木场、锯木坊、采石场、石匠铺、磨坊、饼坊、食堂这7栋首圈生产建筑的建材合计66木料/39切石；预留32格土路与8格石路再用8木料/4切石，剩8木料/4切石。麦粒8只作磨坊种料，原粮不能直接当作面饼；面饼96是16人按32份/日计的3日储粮，建成食堂后才能逐席发餐。教学过程中先建成一间饼坊和食堂，扩村并养兵后再增建第二间饼坊。以上为未模拟的启动提案，实际建造时间、道路布局和座席吞吐仍需原型试玩确认。

## 建议的首个可玩纵向链

不要把32种建筑一次性全做完。建议先实现一条从施工到军队的端到端链，并用它验证角色、经济和镜头反馈：

1. 仓库库存、工人岗位与可见运输任务。
2. 伐木场产原木、锯木坊加工木料；库存目标与运输优先级能显示停工原因。
3. 多个无路蓝图可排队；接通道路后分批运木石到工地共享库存，再调度工人认领不同施工点、推进固定总劳动量。
4. 麦田→磨坊→饼坊→食堂形成可追踪的口粮生产与逐席用餐。
5. 学堂/岗位转换与金锭招募令接入木器、皮甲或铁器装备，最终招募一支可供粮的兵队。

先验证玩家能看懂“缺什么、谁在运、哪里堵、谁在施工、军队要什么”，再扩展剩余建筑与关卡内容。以上是建议迭代顺序，不表示现有游戏已经实现这些系统。

## 来源与访问边界

KaM 数量与机制研究以公开的 KaM Remake 源码为基线：`reyandme/kam_remake`，记录的 HEAD 为 `c24539fd4a992850c83cf1d0c78ea0fb5a532bb5`（2026-10-19 检索）。研究记录该版本源码从 House.Dat 加载28类、另行初始化市集的实现口径；不能把这一源码口径直接当作所有原作发行版的建筑数量结论。详细枚举、表格和代码链接见[研究文档](../research/KAM_REFERENCE_RESEARCH.md)。

同次检索中，Reddit 和 `knightsandmerchants.net` 在当前环境代理阶段返回403；仓库 Discussions 页面返回404，GitHub Issues 的后续批量检索受到429限制。没有读取 Reddit 或官网内容，也没有使用镜像或转发站。可查到的公开源码、少量 Issues 和不可访问项均已在研究文档中逐项注明，不把受限网站内容当作证据。
