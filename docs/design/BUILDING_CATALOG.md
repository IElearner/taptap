# 32种建筑空间与施工目录

本目录为原创空间与数值提案，**不是已实现的占格、容量或工时**。以网格表示建筑 footprint；非矩形建筑通过占格坐标明确表示。门口由 footprint 内的 `entrance.cell` 和朝外的四向向量 `entrance.outward` 指定，外侧相邻格是入口接路点。地块限制、岸线需求和用途说明记在 `site_constraints`。

机器数据在 [building_catalog.json](building_catalog.json)，与[首发经济数据](launch_economy.json)中的32个建筑 ID、名称和顺序一致。执行 `python3 docs/design/validate_building_catalog.py` 可检查覆盖、占地连通、入口位置、库存/人数/施工字段完整性；执行经济数据校验器可另查配方与经济算术。两类校验都不模拟游戏中的寻路、产量平衡、碰撞或实际建造。

## 字段口径

- `footprint`：建筑占用格相对坐标。坐标不代表人物尺寸比例；建筑间道路与临近资源地仍需地图布局测试。
- `storage_capacity_units`：该建筑内部最多容纳的普通物资单位数。食堂桌面餐盘/已上餐不占额外施工工人；任务/胜利目标库存可独立计数。
- `max_operational_staff`：可同时在该建筑工作的专业岗位人数；不包括住户、顾客、驻军或施工队。
- `dining_seats`、`household_capacity`：服务/居住容量。食堂四席是每席单独预约、上菜和清空；此容量与操作员和施工工位分别记录。
- `construction_workpoints`：同一时刻可由工人独占认领的不同施工点数。工人来自普通居民共享调度池，可在搬运、修路和建造之间改派，不是固定建筑职业。
- `construction_total_work_units`：每栋建筑固定总劳动量；单位为一个工人实际工作一秒。材料运输另计；材料分批送入工地共享库存，施工点按自己所需材料独立供料、独立开工，多人不能重复认领同一点。

以下尺寸按功能建议：住居小于大型公共建筑；仓储和兵营较宽；水磨坊、鱼棚、渡口需贴合岸线；市场、食堂、猪圈采用不规则占地以便形成入口/活动空间。所有数字均待首个可玩纵向链的地图与手机镜头测试后调整。

## 分阶段实现范围

首个实现迭代优先做仓库、村民任务调度、伐木场、锯木坊、蓝图与施工点、麦田、磨坊、饼坊和食堂这一条可玩纵向链；再接专业资格与兵员链。其余建筑先作为设计规格，不等于首个版本承诺完整实现32种。
