# 地图生活与施工

道路点击后先出现土路施工点。工人从义仓取材料，沿已通道路走到相邻位置挥锤，进度满后才把新路接入运输网络；隔着尚未完成的路段可以预先规划后续道路和建筑。建筑也需要工人取材、到场施工才竣工。最多两名工人同时施工，实际占用村民人口，缺人时工程等待。建造成本在放置时一次扣除。

生产岗位的工人有独立位置和饥饿状态。搬运工接到任务后从义仓或作坊取货，沿道路把木、石、粮、面粉或熟食送到目的地；手里有货时先送完再去用餐。炊坊没有现成饭菜时，搬运工从义仓运两份口粮入店。炊坊同一时间容纳两人用餐，后来者在店外等候；入店后暂时从地图上隐去，吃完从店门出来并返回原岗位。义仓是未建炊坊时的临时用餐处。

所有这些状态都进入 V2 存档。离线结算继续已开工的建设与运输，已经支付的一餐可以吃完；离线不新增饥饿或进餐消费。现阶段个人用餐覆盖搬运工和生产岗位工人；施工工人、乡勇和未分配岗位的村民尚未接入个人生活循环。人物动作目前使用可运行的绘制回退，手绘图集仍待导入验收。

真实引擎测试：`tests/activities_validate.lua` 检查排队施工、可通行时机、取材、实体货运、炊坊补餐、容量、口粮守恒、读档和 V1 迁移。`tests/activities_showcase.lua` 用于横屏画面截图。手机触控、性能与 TapTap 平台身份仍需扫码实机验证。
