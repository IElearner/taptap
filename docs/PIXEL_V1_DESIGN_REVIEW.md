# 像素 v1 设计验收

**结论：可交付首轮手机试玩。** 这是邀请用户在真实手机上验证像素版触控、性能与设备适配的测试候选，不是商用正式上线，也不代表手机性能或全机型兼容已经通过。现有范围是 11 种建筑与可玩的经营、建造、饮食、养猪和守村路线；原 32 种建筑仍是后续蓝图。

## 设计判断

像素风格已贯穿村景、建筑、道路、角色和界面；近横纵微俯视地图上，村民与建筑入口比例可读。实际全村图可看到伐木场、食堂、麦田、磨坊、牧场和屠宰场与道路的关系。施工动态展示工人靠近不同工作面并完成房屋；伐木接触点窄修后，斧击落在树根位置。厨房录像展示空桌、四席同时进食、分批离席和桌面清空；田地录像展示成熟麦田、农夫进田收割和收割后的田面。猪栏录像展示三猪分散活动和饲养员绕到食槽旁作业，猪脚与槽体、围栏保持分离。守村画面用蓝色乡勇标记与红色山匪标记、血条区分敌我。

实际流程和测试覆盖支持把这一切片交给用户试玩：正常新档八课和守村目标 82/82；native 输入 13/13、存档边界 10/10、844×390 HUD 到规划/建屋 43/43；经济 28/28、食物边界 10/10、战斗与工作转换各 6/6。完整测试细节及原始报告见 [PIXEL_V1_QA_REVIEW.md](PIXEL_V1_QA_REVIEW.md)。这些结果验证了当前实现中的路线，不代表产能已平衡或 32 种建筑已完成。

## 发布边界与待试玩问题

长时 native 录制的 raw 报告保留了常规运行帧耗时尖峰：食堂约 29 秒、农田约 15.5 秒、牧场最高约 8.9 秒；不能把它们归因于加载，也不能写成 raw 全通过。独立无 PNG 对照和既有断言没有发现产品逻辑/资源错误，但这些录制仍不足以替代设备性能测试。844×390 的检查是 native 窗口截图和输入测试，不冒称在真实 iPhone 上测试过。首轮交付的目的正是让用户实机验证，并反馈掉帧、触控和适配问题。

没有剩余的视觉或功能 P0 阻塞首轮手机试玩。当前结论不覆盖正式商用质量、全面性能优化、真实手机兼容、经济平衡或长期内容完整性；这些需通过用户试玩和后续开发继续评估。
