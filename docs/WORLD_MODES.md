# 世界地图与两种玩法

## 有限模式：炊烟再起

固定 22×22 河谷，面向第一次接触生产链经营的玩家。共享出生区确保教学布局稳定，边界外不可营造。木材与石料有固定储量，玩家需要在土地、运输距离和人口之间取舍。

通关需要民居、稻田、磨坊、炊坊竣工，至少四份新口粮运回义仓，并抵御一次山匪。首章由玩家主动开始守村；教学期保留八份救济粮。义仓耐久归零则失败。通关后可重玩或进入无限模式。

## 无限模式：山河拓荒

以相同河谷安全起步，外侧为未勘探迷雾。每次「拓荒」向四周开放八格，不设最终地图边界；消耗逐次增长的木料与口粮，同时发现新木材、石料储量。坐标与种子确定地形，重复访问不会随机重置。外部地区保留间隔八格的通行走廊，避免地形把拓展完全封死。

这不是把有限地图放大：没有通关结算，粮食不再受救济保护，长期断粮损耗义仓。开局四分钟后自动来袭；击退一波后继续经营，下波数量、生命增加，休整时间逐渐缩短到至少七十五秒。玩家通过扩张土地、增设粮链、采石场、驿站与乡勇，在运输效率和守备之间取舍。可用四木四石修复义仓三十点耐久。

「乡里分」记录本局生存时间、拓荒圈数、守住波数与建筑数量；失败后展示本局记录。当前已加入自动存档与离线生产，离线时间不增加生存分。尚未加入跨设备排行榜。

## 手机交互

开场选择有限关卡或无限拓荒，再点击入村。模式菜单会暂停当前局，同模式可直接继续；选择另一模式会开始新局。点击地块营造，单指移动，双指缩放。「归村」回到义仓；无限模式「远方」查看东部新区域，「拓荒」支付探索费用。道路只能延伸，建筑门前须连通；树林和水域暂不可建造。

## 技术与后续

地图按坐标计算，不创建一张无限大的数组。渲染只处理视口附近地块，建筑使用坐标索引，道路连通结果在路网变化时才刷新。运行时间与当前视口、已建路网及建筑有关，不随理论世界总面积增长。

后续可扩展为不同有限关卡、区域资源节点、桥梁、异地粮仓、贸易驿路、云存档及更丰富的军队指挥；不作为本次试玩部署的前置条件。
