# 山河里初步上线版验收标准（V1）

本清单以当前 `scripts/game/` 的 Lua 模拟为基线，限定本轮为“初步上线的手机测试候选版”：单人、可完成教学和经营循环，可交给用户在目标手机实测；本轮不是商用上线认证。验收必须同时看运行中的实际行为与新录制的截图/短视频；旧 V11 截图只能作对照，不能代替复验。任何可在当前 native 流程执行的 P0 不通过都阻止候选版交付。P1 是候选版前应收敛的体验问题；P2 留给后续内容迭代，不扩大本轮范围。当前环境能测 native 触控输入，不等于真实 iPhone 实机测试；实机操作、屏幕适配和性能需明确记作“待用户实机验收”，不得报告为通过。

## 实际玩法规则与实施边界

以下数字和规则来自当前 `Definitions.lua`、`Simulation.lua`、`Meals.lua`、`Construction.lua`，是本轮验收的现行基准。若实现有意改动数值，需同步游戏内说明与验收记录，不能让 UI、教学和模拟各说一套。

| 链路/设施 | 入口与道路 | 工人/生产与库存 |
|---|---|---|
| 义仓 | 初始占地 2×2，义仓南侧的 (10,9) 是全村道路网络起点。 | 初始库存木72、石40、口粮有限模式28/无限模式48；开局3名搬运者。建材和生产物资由搬运者在义仓与设施间转运。 |
| 道路与规划 | 免费按格规划，须连接既有道路；规划格由最多4名建造者施工，完成后才成为物流路网。建筑固定使用南侧门前格 (x,y+1)，每栋设施都须能从该格经连续道路到义仓；门前留空，不能被其他建筑占用。 | 规划可早于接路/施工；建筑材料分阶段送达，未送达的施工点不得开工。道路施工耗用石料，建筑按配方耗木/石。运输任务保留货物至实际取货；输入容量4、输出缓冲最多8、单趟输出最多4。 |
| 麦田→磨坊→食堂 | 每个设施南门接路；生产/输入/供餐只对完成且连通的设施运行。 | 麦田1农夫；四阶段劳作，约90秒产3 grain。磨坊1工人，每 grain 用6秒产2 flour。食堂1厨师，每 flour 或 meat 用6秒产4 food；店内最多8份，四个座位。 |
| 牧场→屠宰场→食堂 | 牧场、屠宰场与食堂各自接路；货物在设施缓冲间转运。 | 牧场1养殖户，每35秒消耗1 grain 撒料，饲料支持约35秒生长；累计有效喂养约105秒出栏1头。屠宰场1屠夫，每 livestock 用8秒产3 meat。食堂可以使用 flour 或 meat；同时到货时输入容量最多4。 |
| 森林→伐木场→义仓 | 伐木场南门接主路，须在6格内有可达树木；樵夫可走林地/草地到树，但运输仍须沿连通道路。 | 1樵夫逐树砍伐、背木回场；搬运者再送木料入义仓。砍倒树状态须存档，树尽后需要拓荒/另寻林地。 |
| 其他生产 | 采石场门前接路；有限地图可采资源尽后需靠无限拓荒的新储量。 | 采石场11秒最多产3石，受当前石储量限制。完成的生产设施默认配1工，可手动在0–2间调度。 |
| 村民与岗位 | 搬运者3人固定；建造者最多4人按需出工；驿站完工增加1名搬运者。生产岗位按人口扣员，最多2人/设施；住宅完工增加4人口。 | 工人、建造者、搬运者、乡勇是不同占员/行为类型，不可假设一人同时占多个岗位。生产工、搬运者、建造者和乡勇都受饥饿/能量影响；进食完成后应返回原工作或路线。食堂每份餐食被1人预占，五人同时到达时只能四人入席，第五人等待。 |

**运输分配基准：** 搬运者通过道路连接取送货。生产设施输入需求在本地输入为0且无在途货时请求1单位；生产缓冲出货时优先匹配已连通、未有入货标记且输入未满的消费者。零库存消费者和等待时间提高优先级，磨坊对 grain 有额外优先级；没消费者时送义仓。单趟目的地容量不超过4，厨灶库存补货不超过2份/趟。验收要确认运输最终守恒、不会重复预扣/重复交货；同资源竞争时按上述优先级能解释去向。

**两种模式与教学终点：** 有限模式地图固定22×22；完成八课后，训练至少3名乡勇并手动开始守村。初战守住后，再拥有民居、麦田、磨坊、食堂且累计产出4份食物即可胜利。教学期间有限模式口粮下限为8，避免新手饥饿软锁。无限模式可用木料和口粮拓荒，费用为木12+每圈6、粮8+每圈4；拓荒增加新区域及木/石储量。240秒后自动来袭，后续波次间隔至少75秒；真正断粮才损耗义仓，失守即失败。无限模式不以结局为目标，记录拓荒圈数、守波和分数。

八课的实玩目标依次为：铺4格道路；建1间民居；建1块麦田；建1座磨坊；累计生产4份食物并建食堂（目标统计实际为累计食物）；建1座伐木场；训练3名乡勇；守住首波（无限模式以守住一波作为教学完成）。按课验证能继续、可退出教学后自由经营并可从设置重读，不要求为了验收扩充额外任务。

**明确的实施差距检查：** 现有规则里食堂不仅生产，还立刻把可用 pantry 空间内的口粮加入店内库存；搬运者另有补粮运输规则，因此要防止同一批食物同时计入缓冲和 pantry。无限模式断粮判定若只检查 warehouse stock.food 会漏掉已存入食堂和在途补粮；本轮按“所有可达食物位置均空”验收，此项为 P0，需做 pantry 保活和全空掉耐久回归。多个消费设施争抢 grain/meat 时，只核对可解释的优先顺序与无丢失，首发不要求复杂的玩家手动排队界面。各工种使用独立人口槽位，本轮不新增跨职业兼职系统。教学“第5课食堂有四席、工人补粮”与第5课目标“累计4份食物”需在实玩时逐字核实一致。

## P0：首发阻断项

| 项目 | 可复现步骤 | 通过标准 |
|---|---|---|
| 桌面多人进食 | 让至少两名村民同时到食堂；从前廊正面、斜侧和近景观察完整入座、吃饭、离席过程；再看一处空席/全空桌面。 | 四席均有独立座位和独立桌面盘茶表现；每名就座者的碗/餐盘、茶具须在对应座位前清楚可辨，角色与餐具一一对应（不能所有人共用桌面一只碗，也不能遮挡到难以辨认）；空席及全空桌面不留下虚位餐具；不穿桌椅、不互相重叠；离席后餐具随之清空、座位状态复位。一次至少两人并行，随后四人满席复验。库存每接待一人准确扣1份，四席不超卖。 |
| 牧场猪与围栏 | 以正常游戏相机观察新建牧场；等待养殖户走出、投喂、猪活动/成长及回栏；检查静止和侧身动画帧。 | 猪脚点始终落在围栏内的地面；侧身猪位于前栏后方时，横杆和柱头清楚遮住猪的相应下缘，猪腹部不得压在上栏或柱顶上而显得踩栏；猪的身体、脚影不穿地或穿到栏外；不压住门口；猪之间可辨认。喂食必须可见且由饲料触发，缺 grain 时生长暂停。至少验收静帧与侧身动作视频。 |
| 道路质感和运输可读性 | 从义仓向外拖动连续多格道路，接通民居、田、磨坊、牧场/屠宰场、食堂与伐木场；观察铺路、建材搬运、成品运输。 | 路面是完整连续且与地表、建筑门口对齐的正式道路资产/材质，线宽、边缘、转角和连接处一致；不接受用少量散石/贴片冒充已铺道路。未接通时货物不传输；铺好后搬运者沿道路从义仓取放资源，路线和货物清楚可见。道路拖动不会误建重复格，建筑入口保持可达。 |
| 生产闭环 A：麦到餐 | 建麦田并接路；分配农夫；等待播种/照料/收割，再建磨坊和食堂，运行至少一轮完整链路。 | UI/库存依次显示 grain、flour、food 增减；实际搬运分别把麦粒送磨坊、面粉送食堂；食堂出餐并补入 pantry，村民从四席进食。当前规则应一致：麦田每轮3 grain，磨坊每1 grain产2 flour，食堂每次消耗1 flour 或 meat、产4 food。缺输入时停产并给出可理解状态。 |
| 生产闭环 B：猪到肉到餐 | 向牧场送 grain；观察投喂和生长；运行到出栏、屠宰、肉送达食堂并制餐。 | 饲料消耗、牲畜库存、肉库存、食堂投入与 food 产出均守恒且可见；牧场每次投喂消耗1 grain，缺料停止生长；屠宰场每头 livestock 产3 meat；食堂肉路线可独立工作。 |
| 生产闭环 C：林木到建筑 | 在树林六格内建伐木场并接路，观察樵夫伐树背木回场，再由搬运者送义仓；用木料规划并建成一座建筑。 | 砍伐目标树消失且存档后不复生；樵夫、背木、入场、义仓入库可辨认；木料不凭空增长；建筑可先多点规划，材料分批运输后施工。完成后门口、道路和建筑占地不冲突。 |
| 职业、饥饿与四席 | 安排工人并运行生产；让至少5名角色在相近时间到食堂，确保一人正在工作、一人为搬运者。 | 各职业外观/工作行为能区分；饥饿会触发用餐，吃完恢复并返回原工作/运输目标；最多4人同时占席，第5人排队，空位释放后入座；没有食物时不扣餐、不假装吃饭、不丢失工作。 |
| 存档与离线 | 保存正在生产且有在途货物/角色状态的游戏，退出后等待至少1分钟，再读档；另测暂停存档和已结束存档。 | 建筑、道路、占地、库存、作物阶段、牧场饲料/生长、伐木树状态、运输中任务、角色和教程进度能恢复且不重复结算；运行中离线按真实间隔推进，最多8小时；暂停、教学未开始、胜负结束不推进；读档不崩溃、不产生负库存或重复物品。给出离线结算摘要。 |
| 无限模式有粮不误判断粮 | 把仓库口粮用服务运输补进已连通食堂，使仓库归零而食堂 pantry 仍有口粮；必要时在补粮运输途中检查状态。再耗尽仓库、所有可达食堂 pantry 和在途补粮。 | 只有总可达/将达口粮为0时，每15秒才损耗义仓耐久4点。有 pantry 或已预扣的食堂补粮在途时不应误报断粮/扣耐久；全空后按节奏扣耐久并能导致失守。粮食转移不应因存放位置变化触发饥荒。 |
| 模式、教学及 native 触控流程 | 新档分别进入有限与无限；完整走八课教学；用当前 native 输入流程模拟拖地图、点选建筑、规划多格路、缩放/旋转（若有）、打开菜单及暂停。 | 有限地图边界固定且八课能顺序完成；无限地图可拓荒且保持连续可达；新手无需猜按钮能完成首条路、首建筑和粮食链；native 触控映射无拖图误点建造、无面板遮挡操作；退出/暂停/重开入口可发现。教学不会软锁、目标文案与实际解锁一致。真实 iPhone 实机操作/适配/性能单独记“待用户实机验收”，不可据 native 结果判通过。 |

## P1：首发体验收敛

- 运输、工人、饥饿、施工、缺料和道路断连应有稳定的短状态提示；同一时刻避免相互覆盖到无法读懂。
- 建筑规划预览必须按真实占地显示，含 L 形驿站凹角、门前通行格和道路冲突；拒绝时说明原因。多点道路拖动与重复点按有清晰反馈。
- 生产链 UI 明确显示输入、输出、生产计时/停产原因和库存单位，不能只靠观察小人推断。
- 四席、排队与食堂补货在不同镜头缩放下仍可读；角色不长时间堵门或绕路。
- 无限模式拓荒边界有清楚提示，地图资源可供新一轮生产；有限模式胜负条件和军务入口易懂。
- 连续运行十分钟无明显卡死、角色永久迷路、货物负数或帧率骤降；主要操作可由触控完成。

## P2：首发后迭代

- 增加更多食谱、建筑升级、村民个性/对白、季节和天气、额外地图主题与任务。
- 增加更丰富的经济报表、装饰物、音效变化和高级调度工具。
- 扩展无限模式的长线目标与敌袭种类；当前只要求基础拓荒/生存循环稳定。
