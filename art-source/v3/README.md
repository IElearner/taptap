# 山河里 · 三维建筑与人物替换版 3D-03

这套原创网格由 `dev/create_village_models.py` 在 Blender 内制作，再由项目自带的 `.cli/blend_to_urhox.py` 导出。以 v2 美术源图确定材质、建筑功能和人物身份；当前造型精度仍低于源图中的绘画细节。

## 实际交付

- `village-models.blend`：完整可编辑源文件。
- `assets/model/village-v3`：122 个真实网格、25 种材质和 Maker 生成的元数据。
- 义仓、民居、磨坊、食堂、伐木场、采石场、驿站、乡勇营、屠宰场、牧场分别具有地基、木架、墙体、半屋顶、成品五个阶段。无路的规划仍然只显示测量桩。
- 驿站主屋与装卸棚独立建模，东北凹角保持空地；磨坊水车为独立的空心辐条网格。
- 食堂有四个真实座位。用餐时采用去除前棚、前梁和屋顶的剖视模型，显示四个真实人物，不叠加人物插画。导出时通过四条从坐席头部朝相机方向的射线，检查模型遮挡。
- 麦田具有种子、幼苗、青麦、成熟四种网格；成熟麦穗、叶片和弯曲茎秆具有真实体积，相邻田地仍只保留外边界围栏。
- 四种普通村民、厨师、屠夫、男女乡勇、山贼共九种人物造型，各有头部、衣身及四类肢体网格。
- 锤、斧、锄、镰、水壶、饭碗、筷子为不同的三维物件，按实际工作状态显示。

人物采用网格分段与节点关节动画，包含肩、肘、髋、膝关节，不是绑定骨架权重的蒙皮模型。行走、搬运、施工、种田、吃饭持续由模拟时间驱动，暂停和读档不会改变人物身份。模型没有使用建筑/人物图片朝向相机的方式替代。

## 重建

在仓库根目录运行：

```bash
blender --background --python dev/create_village_models.py
```

生成器同时更新 `scripts/game/VillageModelsManifest.lua` 的准确资源路径。然后通过 Maker 的 `generate_resource_meta` 为新增资源生成元数据，不能手工制造 UUID。

引擎内资源复用与材质应用由 `scripts/game/VillageModels.lua` 负责。建筑占地、物流、施工总工作量及存档数据格式不变；旧存档按原来预留的土地大小显示。

## 验证

使用 `tests/village_models_validate.lua` 验证全部网格、材质、人物身份、用餐工具、关节运动和施工阶段；使用原有布局、四面施工、农田动作及角色测试进行回归。宿主的 `/home/agent/logs/lua` 日志路径错误仍会令本地验证器总体显示 FAIL，需要与 `test_result` 中的功能断言结果分开报告。
