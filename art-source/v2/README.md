## 接入范围与质量界限

本轮完成的是主要美术类别的第一套源图。合成表带浅色背景与绘制阴影，不能直接视为透明精灵、严格 UV 图集、法线贴图、可用网格模型或骨骼动画。图内细节也存在生成误差，例如食堂座位数量和摄像机角度；游戏逻辑继续保持四个座位，不能根据源图自动改变规则。

`materials.png` 按单元在引擎内裁取，仅用于真实网格的表面颜色；人物、建筑在场景中继续采用三维几何与关节动作。草地材质需要独立实机检查，避免重复纹理和过密草线影响可读性。

当前三维建筑轮廓和人物模型尚未全部重做，不能将这些源图展示为新版本游戏截图，也不能声称整套可运行模型替换已经完成。本轮不发布模型尚未完成的美术测试包。

后续制作顺序：依据建筑图更新网格与各施工阶段 → 按四向人物图制作可绑定角色 → 调整关节动作和工具挂点 → 场景中校正建筑/人物/道路比例 → UI 精确切分与状态接入 → 手机实测后构建。

本地检查：Lua LSP 零错误；资源检查 124 项断言、布局及道路检查 75 项断言通过。验证器总状态仍包含宿主日志目录无法打开的既知错误，不能将断言通过描述为运行器整体通过。

后续更新：建筑和人物已在 3D-03 中换为 Blender 导出的原创网格与节点关节动画，详见 [第三版说明](../v3/README.md)。上文未接入状态记录的是源图刚生成时的阶段。
